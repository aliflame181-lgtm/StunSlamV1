# StunSlamMacro (Fabric, Minecraft 1.21.11, Java 21)
Client-side only. Needs Fabric API.
- J = toggle ON/OFF (saved)      - R = run one stun slam (only while ON)
Look at a target with an axe and a mace in the hotbar, press R: axe hit, then mace hit on the next tick.
Config: config/stunslammacro.json (stepDelayTicks 1 = two ticks total, 0 = same tick)
